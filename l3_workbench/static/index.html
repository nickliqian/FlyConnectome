开始一次 L3 实验

  1. 选择场景，设置出生位置、摩擦和粘附强度，点击「重置场景」。
  2. 在地图上拖动目标点，点击「开始运行」。可随时暂停或步进 0.1 秒。
  3. 切换手动控制、调整罗盘噪声或遮挡罗盘，观察航向与轨迹变化。
  4. 暂停后导出实验，结果包包含视频、CSV、参数和干预时间记录。

物理计算可能慢于真实时间。页面显示仿真时间与计算速度，视频按仿真时间播放。目标距离和真实航向来自仿真状态，航向估计来自 CX 网络。

第一版支持平地。坡面、障碍、风和气味尚未建模。地面摩擦和粘附改变后可能影响行走稳定性；标定失败时请恢复默认场景。

同一服务的多个页面共享一个实验。重置会建立新实验目录，旧数据仍保留在 outputs/l3-workbench。
