# 图片二选一奖励学习

用户已确认：展示圆形／三角形图片，学习模块作答，正确 +1、错误 0，持续训练；独立测试冻结参数；训练后的选择可由 L3 行走演示。

新增 `/learning.html`，保留导航工作台。图片为 32×32 实际位图，随机位置、大小和颜色。编码器只接收像素，裁剪前景并缩放为 8×8 占用率，不接收类别或图片生成参数。决策器为两动作 softmax 策略，使用所选动作的奖励进行策略梯度更新。两类平衡呈现；种子可复现；训练、测试、演示使用独立随机流。测试固定留出集，不更新权重、训练随机流、训练计数或奖励。明确这不是生物连接组学习或复眼识字。

训练提供单轮、批量、停止；反馈包括本轮选择与概率、奖励、最近 50 轮正确率、累计奖励、独立测试及曲线。训练状态和记录可导出 JSON/CSV；页面会话内保留，刷新会重新开始并明确提示。上限 10000 轮，避免无限内存。

L3 演示冻结当轮图片及选择，并交换左右选项；物理目标为 (18, ±10) mm，重置共享物理实验，待确认后运行，真实距离 <4 mm 判定到达。训练正确和到达分别展示。支持暂停／继续，检测其他页面更换实验／目标并停止跟随。物理失败不修改识别奖励。快速训练不需要启动物理进程。第一版只用生成图形，不支持任意照片上传。

视觉沿用实验室蓝灰色，学习画布为主视觉：左图片和两个选项，右训练控制，下方学习曲线与逐轮记录，L3 演示单独观察区。中文系统字体，背景 #f4f7fa、文字 #20354e、蓝 #326da8、绿 #27806c、错误 #a14c52、线 #dce4ec。移动端单列，控件有标签，颜色外另有文字反馈。
