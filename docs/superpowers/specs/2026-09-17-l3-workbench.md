# L3 本地交互工作台

用户已批准前一轮提出的第一版范围，并要求实施。

保留现有 Python L3 控制器，以本地网页操作真实 MuJoCo 仿真。新增的网页服务使用项目内 conda 环境和 Python 标准库；独立子进程使用已有 `.venv-l3` 物理环境，不修改旧环境。子进程主线程持有 GLFW 上下文，HTTP 服务不等待物理计算。

界面：浅灰白实验台、深蓝文字、青蓝轨迹、橙色目标，系统中文无衬线字体。左侧配置，中间真实画面和目标地图，右侧实时控制，底部航向曲线、CX 活动和六腿接触。地图采用毫米世界坐标，支持拖动目标和新增／删除目标。所有模型边界在帮助文案中注明。

第一版：平地、出生位置与方向、摩擦与粘附强度；自主导航或左右手动信号；罗盘噪声及遮挡；开始／暂停／0.1 秒步进／重置；三种跟随视角；真实姿态、航向估计、速度、目标距离、CPG 相位、粘附指令、接触状态；JSON 配置导入导出；CSV、事件日志、MP4 打包导出。

场景参数重置生效，导航／传感参数下一控制周期生效。暂停保留物理状态。仿真上限 60 秒，默认 10 秒；记录限制由此约束。导出在暂停或完成后进行，视频按仿真时间编码。配置、干预事件与随机种子随结果保存。

不宣称实时速度、不伪造反馈。罗盘是体姿加噪声，位置来自仿真真值。第一版不包含障碍、坡面、视觉感知或气味模型。

验证：参数边界和协议单元测试、真实子进程的初始化／步进／暂停／重置／导出集成测试、浏览器操作及截图检查。服务仅监听 loopback，校验 Host、Origin 和写请求令牌，不暴露项目任意文件。
